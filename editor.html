Role colours JSON

One JSON object. Each key names a role, each value is its hex — #rrggbb, #rgb or without the #. Keys are case-insensitive; every key is optional.

ground sets the colour behind the level, not a role, and is undone with the level.

tileBg sets the skin-wide tile background. Any role key with Bg appended — floorBg, boxPlacedBg — sets that role's own background, which wins over tileBg. Backgrounds apply to unbound roles too.

Only bound roles are recoloured, and each keeps its ink mode. Unknown keys and values that are not a hex are reported and skipped. 

{
  "floor": "#1a1c2c",
  "goal": "#ffcd75",
  "wall": "#333c57",
  "box": "#a7f070",
  "boxPlaced": "#38b764",
  "player": "#ef7d57",
  "tileBg": "#1a1c2c",
  "goalBg": "#29366f"
}
